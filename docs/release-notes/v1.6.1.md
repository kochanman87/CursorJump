## v1.6.1

### バグ修正
- **3 画面マルチモニタ環境でジャンプ後にラグ・砂時計カーソルが出る不具合**: 軌跡/収縮円エフェクト用の透明オーバーレイウィンドウをジャンプのたびに新規生成・破棄していたため、3 画面 (異 DPI) 環境ではレイヤード HWND 生成コストでカーソルが一瞬砂時計化し、操作可能になるまで体感的な遅延があった。
  - 透明オーバーレイをアプリ起動時に **1 枚だけプリアロケート**して使い回す方式に変更。ジャンプ時は Canvas に要素を追加・アニメ完了で個別削除するのみで、HWND の作成/破棄が走らない。
  - 拡張スタイルに `WS_EX_NOACTIVATE` を追加し、Show 時のアクティベート同期 (砂時計の主因) を抑止。
  - モニタ抜き差し (`DisplaySettingsChanged`) に追従してオーバーレイサイズを自動再調整。

### 機能改善
- **マウスホイールトリガーを単一項目に統合**: v1.5.2 で「ホイール上スクロール」「ホイール下スクロール」を別ボタンとして追加していたが、設定画面では「マウスホイール」1 項目に統合。
  - ナビゲート系のショートカット (Set A / Set B / モニタ内) に割り当てた場合、**ホイール下スクロールで次の座標、上スクロールで前の座標** (1→2→3 と 3→2→1) を循環できる。
  - 座標保存・削除モード起動など方向の意味がないアクションでは上下どちらでも発火。
  - 旧 settings.json で WheelUp/WheelDown が個別割り当てされている場合は従来通り動作 (移行は行わない)。

### 内部変更
- `OverlayService` を `IDisposable` 化し、軌跡/収縮円/一括収縮円が共有する `_trailOverlay` シングルトンを導入。`MainWindow.OnSourceInitialized` 末尾でプリアロケート、`OnClosed` で破棄。
- `MouseHookEventArgs` に `WheelDirection Direction` プロパティを追加。フックがホイール由来のイベント発火時に上下方向を伝搬。
- `MouseButtonType.MouseWheel` を追加 (enum 末尾)。旧 `WheelUp` / `WheelDown` は後方互換のため enum 値・ローカライズキーともに維持。
- `CoordinateStore` に `GetPrev()` / `GetPrev(connectedDeviceNames)` / `GetPrevInMonitor(deviceName)` を追加。
- ユニットテストに `GetPrev` 系の循環/接続モニタフィルタ/モニタ別循環のケースを追加。
