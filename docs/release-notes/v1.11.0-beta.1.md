### 新機能（Pro・お試し）: 要素へジャンプ

- 修飾キー（初期値 Ctrl+Alt）を押しながらマウスを少し動かすと、その方向にあるボタンやリンクへカーソルがジャンプします。押したまま動かし続けると、次の要素へ順に移ります。
- 画面上の複数のアプリ・複数のモニタをまたいでジャンプできます。他のウィンドウに隠れている要素には飛びません。
- 普段よくクリックする要素を学習し、ジャンプ先として優先します（Web ページはサイトごとに学習）。学習データはこの PC の中にだけ保存されます。
- ブラウザ（Chrome / Edge）のブックマークバーは、初期設定ではジャンプ先から外します。
- 設定画面の「Pro 追加機能」→「要素へジャンプ」で ON にしてください（初期状態は OFF）。
