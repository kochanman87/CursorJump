## v1.7.4 (pre-release)

### 診断ログ強化（軌跡が途中で消える症状の原因特定用）
- カーソル移動時の軌跡エフェクト描画（`ShowTrail`）と座標保存時の収縮円（`ShowShrinkCircle`）について、呼出時のパラメータ・オーバーレイの可視状態（`IsVisible`/`Opacity`/`Topmost`）・追加した要素数を `debug.log` に記録するようにしました。
- オーバーレイの再利用／再生成のどちらが起きたかも明示的に記録するようにしました。
- メモリ診断ログ（`MemDiag`）に直近 1 分間でアニメ完了処理が成功した要素数（`RemovedSinceLastTick`）を追加しました。

### 内部変更
- 機能や操作感に変更はありません。
