## v1.10.0

### 「クリック位置に戻る」の履歴を画面上に表示（Pro）

- 最近のクリック位置に薄い番号付きマーカーを常時表示します。表示する件数は「履歴の深さ」に従います。
- 番号は新しいクリックから1、2、3…の順です。次に戻る位置を二重の枠で示し、クリックや移動に合わせて更新します。
- 設定の「クリック位置に戻る」から表示のオン／オフ、色、濃さ（10〜100%）を変更できます。初期値は青、濃さ35%です。
- マーカー越しに通常のクリック操作ができます。座標編集モード中は履歴マーカーを一時的に隠します。
- 履歴は従来通りアプリ実行中のみ保持します。再起動後は新しいクリックから記録します。
