## v1.12.0

### 設定画面をシンプルにしました（UI の変更）

- 左のメニュー（操作 / 見た目 / 全般 / ヘルプ）で切り替える形にしました。
- 保存ボタンをなくし、変えた所はその場で保存されるようにしました。組み合わせに問題があるとき（ショートカットの重複など）は保存せず、画面の下に理由を表示します。Esc で閉じられます。
- 操作は 1 行に 1 つずつ並べ、今の割り当てを行の右に表示します。行を押すと、その操作だけ編集欄が開きます。
- 色は「1 つ目 / 2 つ目のリストの色」の 2 つにまとめました。効果ごとの色や線の太さ・濃さは「詳細」から変えられます。
- ヘルプに、位置を保存して順に移動する様子のアニメーションを追加しました。
- 「前面ウィンドウ中央へ」は「最前面ウィンドウへ」に名前を変えました。

### その他

- 新しくインストールしたときの「保存した位置へ移動」を Ctrl + Win + マウスホイールにしました（今お使いの割り当ては変わりません）。
- 英語表示のとき、設定画面の一部（自動起動の見出しと説明、バージョン・前回確認の表記）が空欄や日本語のままになっていたのを修正しました（v1.10.2 の内容）。
