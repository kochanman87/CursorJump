## v1.5.0

### バグ修正
- **マルチモニタでジャンプ位置がずれる不具合への対策 (バグ1, 仮説修正)**: カーソル移動を `SetCursorPos` から `SendInput(MOUSEEVENTF_ABSOLUTE | VIRTUALDESK)` に変更。PerMonitorV2 環境で異 DPI モニタ間ジャンプ時に `SetCursorPos` が DPI 仮想化により別座標へ飛ぶ既知挙動を回避する。万が一 regression が出た場合は設定ファイル `UseSendInputForJump` を false に変更で従来動作に戻せる
- **モニタ取り外し後に座標が残る不具合を修正 (バグ3)**: 3画面で保存した座標を 1画面構成に戻したとき、消失モニタ上の座標へジャンプしてカーソルが画面端で止まる不具合を修正。接続中のモニタに無い座標は自動的にスキップされる (削除モードでも非表示。再接続すれば復活)
- **設定画面が小型ノート PC ではみ出る不具合を修正 (バグ2)**: 起動時に作業領域を超えないようウィンドウサイズをクランプし、画面中央に再配置する
- **Windows 11 環境で常駐中に左クリックが効かなくなる症状への対策 (バグ4)**: フックタイムアウトで UP イベントが取り逃がされた場合に消費フラグが残留する問題を修正。500ms 経過したら自動失効するようタイムアウトを導入

### 機能追加
- **診断ログ機能を強化**: 設定画面「情報」タブに「ログを開く」「ログフォルダを開く」ボタンを追加。Notepad で開けるので、社内 PC でも印刷経由で外に出せる
- **詳細ログモード**: 「情報」タブのトグルから ON/OFF 可能。ジャンプ前後のカーソル座標、モニタ別 DPI、プロセスの DPI 認識レベル、モニタの物理インチを記録する。マルチモニタ不具合の原因特定用 (常用すると重くなるため通常は OFF 推奨)

### 内部変更
- DebugLog をバックグラウンドスレッドの非同期キュー方式に変更し、フックコールバック内のログ I/O 遅延を解消
- xUnit テストプロジェクト (`tests/CursorJump.Tests`) を新設。`MonitorFilter` と `CoordinateStore.GetNext(connectedMonitors)` のロジックをユニットテストで担保
