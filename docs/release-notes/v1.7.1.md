## v1.7.1

### 機能追加
- **座標表示モード中に Set B（2 つ目の座標リスト）へ追加できるようになりました（Pro 版）**: 空きエリアをクリックして Set A に追加した直後（350ms 以内）に同じマーカーを再クリックすると、Set A から取り除いて Set B に移動します。
  - 1 回目クリック: 従来通り即座に Set A へ追加（ラグなし）。
  - 2 回目クリック（350ms 以内）: 橙色の収縮エフェクトとともに Set B へ昇格。
  - 削除モードヘルプ（画面隅のガイド）に `[ダブルクリック]  追加 (2 つ目)` の操作説明を追加（Pro 版のみ表示）。
  - 設定画面「使い方」タブの座標表示・削除の説明文にダブルクリック追加の案内を追記。
