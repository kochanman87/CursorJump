## v1.7.5 (pre-release)

### 不具合修正: 軌跡・収縮円エフェクトが突然表示されなくなる症状
- カーソル移動時の軌跡や座標保存時の収縮円エフェクトが、使用しているうちに突然表示されなくなる症状を修正しました。
- 原因は、エフェクト表示用の常駐ウィンドウが、削除モードや他アプリの全画面表示などをきっかけに画面の重なり順（最前面）から沈み込み、描画はされているのに他のウィンドウの背面に隠れてしまうことでした（アプリ再起動で一時的に直るのはこのためでした）。
- エフェクトを描画する直前に、常駐ウィンドウを最前面へ戻す処理を追加して恒久対策しました。フォーカスは奪わないため、操作中のアプリには影響しません。

### 内部変更
- 診断用ログ（軌跡エフェクトの状態・メモリ使用状況）は引き続き記録されます。
